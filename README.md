# 📰 주린이 뉴스 번역기

어려운 경제 뉴스를 주식 초보자('주린이') 눈높이에 맞게 실시간으로 번역해 주는 웹 앱입니다.

## 주요 기능

1. **쉬운 말 번역** — 기사를 붙여넣으면 문장별로 쉬운 한국어 해설과 세 줄 요약을 보여줍니다.
   - Google Gemini API를 사용해 자연스러운 번역을 생성합니다. (`gemini-2.5-flash` → `2.0` → `1.5` 순으로 키가 지원하는 모델을 자동 선택)
   - API 키가 없으면 내장 경제 용어사전(45개 용어) 기반 간이 번역으로 자동 폴백합니다.
2. **문장 호버 → 관련 종목 동향** — 문장에 마우스를 올리면 그 문장과 관련된 종목 리스트가 팝오버로 뜨고, 현재가·등락률·최근 30일 스파크라인을 보여줍니다.
   - 기사에 직접 언급된 종목 + 섹터 키워드(반도체, 2차전지, 방산 등 17개 섹터) 기반 관련주를 매칭합니다.
3. **종목명/코드 클릭 → 가격 차트** — 본문의 종목명(파란 글씨)이나 6자리 종목코드를 클릭하면 캔들차트 + 거래량 모달이 열립니다. (1개월/3개월/6개월/1년 전환, 크로스헤어 지원)
4. **용어 툴팁** — 점선으로 표시된 경제 용어에 마우스를 올리면 쉬운 설명이 나옵니다. 채권·펀드 용어(듀레이션, YTM, 신용등급, TER, 괴리율, 환헤지 등) 포함 58개 내장.
5. **뉴스 ↔ 금융상품 연결** — 문장의 테마(금리 인하, 반도체, 배당, 환율 등 13개)를 인식해 관련 ETF·펀드를 위험등급·연보수·이유와 함께 보여줍니다. 상품 클릭 시 가격 차트가 열립니다. (투자 권유가 아닌 참고 정보)

## 실행 방법

```bash
pip install -r requirements.txt

# (권장) Google Gemini API 키 설정
export GOOGLE_API_KEY=...

python run.py
# → http://localhost:8000
```

**API 키 발급:**
- [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급
- 키가 없거나 호출에 실패하면 내장 용어사전으로 자동 폴백 (실패 사유가 화면 상단에 표시됨)

## 시세 데이터

- 야후 파이낸스 공개 차트 API(지연 시세)를 짧은 타임아웃으로 시도합니다.
- 네트워크가 막혀 있거나 실패하면 종목 코드로 시드된 **결정적 모의 시세**로 자동 폴백하며, 화면 하단에 데이터 출처가 표시됩니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `POST` | `/api/translate` | `{"text": "..."}` → 문장별 쉬운 번역 + 용어 + 관련 종목 |
| `POST` | `/api/quiz` | `{"text": "...", "question_count": 3~20}` → 번역/용어/종목 기반 객관식 퀴즈 생성 |
| `GET` | `/api/stocks/{code}` | 현재가, 등락률, 최근 30일 스파크라인 |
| `GET` | `/api/stocks/{code}/chart?range=1m\|3m\|6m\|1y` | 일봉 OHLCV 시계열 |

## 구조

```

├── translator.py  # Google Gemini 번역 + 용어사전 폴백
├── stocks.py      # 종목/섹터 매칭, 시세(라이브→모의 폴백)
├── products.py    # 테마 키워드 → 관련 ETF·펀드 매칭
└── data/
    ├── stocks.json    # 종목 유니버스(44종목) + 섹터 키워드

    └── glossary.json  # 경제·채권·펀드 용어사전(58개)
extension/
├── manifest.json      # Chrome/Edge 확장 설정
├── background.js      # API 프록시 (CORS 우회)
├── content_script.js  # 기사 위 직접 상호작용 (핵심)
├── popup.html/js/css  # 팝업 UI (수동 입력용)
└── README.md
static/
├── index.html
├── style.css
└── app.js         # 팝오버·툴팁·캔버스 차트 (외부 라이브러리 없음)
```
